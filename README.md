# Бот для общения с нейросетью, с сохранением контекста переписки и возможностью переключаться между стилями общения

## ✨ Особенности

- Конвертация голосовых сообщений в текст
- Поддержка разных стилей общения (деловой, дружеский, ироничный)
- История диалогов с автоматической очисткой
- Работает с OpenAI через OpenRouter API
- Простая настройка и развертывание

## 🛠 Технологии

- Python 3.11+
- Aiogram 3.x (для Telegram API)
- SQLite (хранение данных)
- OpenRouter API (доступ к GPT-3.5-turbo)
- SpeechRecognition (распознавание голоса)
- Pydub (обработка аудио)

## ⚙️ Установка

1. Клонируйте репозиторий:
git clone https://github.com/Vladimir-Topor/AI_bot.git
cd AI_bot

2. Установите зависимости из requarements.txt
3. Создайте BOT_TOKEN и GPT_TOKEN
4. python main.py и радуемся
